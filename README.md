# Palm Pilot Galaxy 🚀

**Palm Pilot Galaxy** is an innovative gesture-controlled space shooter that lets you control your spaceship using your own body movements. Experience a new way to play PC games without a traditional keyboard or controller!

Powered by computer vision, Palm Pilot Galaxy offers multiple control modes, allowing players to pilot their spaceship using **hand gestures, head movements, eye movements, or body movements**.

### 🎮 Key Features
- 🚀 Gesture-based spaceship control
- ✋ Multiple control modes: Palm, Head, Eyes, and Body
- ⚙️ Customizable turning speed, acceleration, and braking
- 🏆 Leaderboard to compete for high scores
- 🎯 Intuitive gameplay with a unique interactive experience
- 💻 Designed for Windows 10 and Windows 11

Palm Pilot Galaxy is part of the Palm Pilot project by **Ceyntax**, exploring the future of hands-free, motion-controlled gaming.
